### Data sources:

The data used in this project were obtained from the **UCSC Xena platform**, specifically from the GDC Xena Hub.

-   Gene expression data: [TCGA-LAML STAR COUNTS](https://xenabrowser.net/datapages/?dataset=TCGA%20LAML.star_counts.tsv&host=https%3A%2F%2Fgdc.xenahubs.net&removeHub=https%3A%2F%2Fxena.treehouse.gi.ucsc.edu%3A443)

-   Clinical metadata: [TCGA-LAML Clinical Data](https://xenabrowser.net/datapages/?dataset=TCGA-LAML.clinical.tsv&host=https%3A%2F%2Fgdc.xenahubs.net&removeHub=https%3A%2F%2Fxena.treehouse.gi.ucsc.edu%3A443)

-   Gene annotation: [GENCODE V36 ANNOTATION](https://gdc.xenahubs.net/download/gencode.v36.annotation.gtf.gene.probemap)
