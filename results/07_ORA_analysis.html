DEGs and background

To perform ORA, we need two sets of genes: one containing the DE genes (the ones with a q_value lower than 0.05) and one containing all the gene tested in the DE analysis (background). Unlike the volcano plot of the previous section, in the ORA we select genes based only on their significance and not on their effect size because in this analysis we want to identify biological processes enriched among all statistically significant genes, including those with relatively small expression changes.

deg_genes <- lm_results |>
  filter(q_value < 0.05) |>
  pull(gene_id) |>
  unique()

background_genes <- lm_results |>
  pull(gene_id) |>
  unique()

Define the ORA gene sets

To perform ORA, we first restrict the analysis to genes that are represented in both the differential expression results and the GO:BP gene sets.

deg_go <- intersect(
  deg_genes,
  bp_df$ensembl_gene
)

background_go <- intersect(
  background_genes,
  bp_df$ensembl_gene
)

Filter gene sets

We filter the GO:BP gene sets to retain only genes included in the background gene set.

bp_df_filtered <- bp_df |>
  filter(ensembl_gene %in% background_go) |>
  select(gs_name, ensembl_gene) |>
  distinct()

Filter gene sets by size

To avoid including gene sets that are too small or too large, we restrict the analysis to gene sets containing between 10 and 500 genes from the background, following the approach presented in the course 22150 Introduction to Systems Biology (Vitting-Seerup, 2025).

  • Small gene sets may produce unstable enrichment results because even a few overlapping genes can have a strong influence on the statistical test.

  • Large gene sets may be too broad and provide less specific biological information.

bp_df_group_size <- bp_df_filtered |>
  group_by(gs_name) |>
  summarise(
    gene_set_size = n_distinct(ensembl_gene)
  ) |>
  ungroup() |>
  filter(gene_set_size >= 10, gene_set_size <= 500)

Now that we have deleted the extreme groups, we filter the original bp_df_filtered.

bp_df_filtered <- bp_df_filtered |>
  semi_join(bp_df_group_size, by = "gs_name")

How many DEG in each process?

deg_overlap <- bp_df_filtered |>
  filter(ensembl_gene %in% deg_go) |>
  group_by(gs_name) |>
  summarise(
    n_DEGs = n_distinct(ensembl_gene)
  ) |>
  ungroup()

Fisher test

To perform the over-representation analysis, we construct a contingency table for each gene set. The table contains four categories:

  • a: DEGs inside the gene set.

  • b: DEGs outside the gene set.

  • c: Non-DEGs inside the gene set.

  • d: Non-DEGs outside the gene set.

ora_table <- bp_df_group_size |>
  left_join(deg_overlap, by = "gs_name") |>
  mutate(
    n_DEGs = replace_na(n_DEGs, 0),
    a = n_DEGs,
    b = length(deg_go) - a,
    c = gene_set_size - a,
    d = length(background_go) - a - b - c
  )

We then apply Fisher’s exact test to each gene set to determine whether DEGs are over-represented compared with the background. The alternative hypothesis is set to "greater", meaning that we test for enrichment of DEGs within each gene set.

ora_results <- ora_table |>
  rowwise() |>
  mutate(
    p_value = fisher.test(
      matrix(c(a, b, c, d), nrow = 2, byrow = TRUE),
      alternative = "greater"
    )$p.value
  ) |>
  ungroup()

Multiple test correction

Since multiple gene sets are tested, we adjust the p-values using the Benjamini–Hochberg (BH) method to control the false discovery rate (FDR).

ora_results <- ora_results |>
  mutate(
    q_value = p.adjust(p_value, method = "BH")
  )

Significant gene sets

We select the significantly enriched gene sets using an adjusted p-value (q-value) threshold of 0.05 and rank them by increasing q-value.

significant_pathways <- ora_results |>
  filter(q_value < 0.05) |>
  arrange(q_value)

Conclusions

Three enriched processes identified: histone lysine demethylation, protein demethylation and demethylation (significant, but with a lower statistical significance than the other two).

These pathways are closely related and, from enriched_genes_annotated, they share the same four genes: KDM5C, KDM5D, KDM6A and UTY. Therefore, they should not be interpreted as three independent biological findings but rather as evidence of enrichment in demethylation-related processes, particularly histone lysine demethylation.

All four genes are located on the sex chromosomes. As expected, the Y-linked genes KDM5D and UTY show higher expression in males, while the X-linked genes KDM5C and KDM6A show higher expression in females. These differences suggest sex-related variation in the expression of epigenetic regulators, which may contribute to the observed enrichment of demethylation-related processes
