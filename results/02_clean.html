Data wrangling

Checking gene identifiers

Before reshaping the expression dataset, I check whether the gene identifiers are missing or duplicated. Each gene should be identifiable in the expression dataset so that the measurements can be associated with the correct gene.

# Check the completeness and uniqueness of gene identifiers
laml_expression |>
  summarise(
    total_rows = n(),
    unique_gene_ids = n_distinct(Ensembl_ID),
    missing_gene_ids = sum(is.na(Ensembl_ID))
  )
# A tibble: 1 × 3
  total_rows unique_gene_ids missing_gene_ids
       <int>           <int>            <int>
1      60660           60660                0

The expression dataset contains 60,660 gene identifiers, all of which are unique. No missing gene identifiers were found. Therefore, no gene identifier cleaning or removal is necessary before reshaping the dataset.

Checking and matching samples

Checking for duplicate sample identifiers

The metadata contains more rows than unique patient cases. Before removing any observations, I investigate whether sample identifiers occur more than once. This is important because multiple samples may belong to the same patient.

# Count how many times each sample ID occurs
laml_metadata |>
  count(sample, sort = TRUE) |>
  filter(n > 1)
# A tibble: 0 × 2
# ℹ 2 variables: sample <chr>, n <int>

No duplicate sample identifiers were found. However, the metadata contains 278 records representing 200 unique patients. This indicates that some patients have multiple samples. I therefore retain the sample-level records rather than removing observations based on patient ID.

Reshaping expression data

The expression dataset is organised in a wide format, where each row represents a gene and each sample has its own column. To prepare the data for subsequent analysis, I reshape the expression data into a long format and combine it with the corresponding patient metadata.

Testing the reshaping and metadata join on a subset

  slice_sample(n = 10)

  pivot_longer(
    cols = -Ensembl_ID,

Saving cleaned data

After reshaping the gene expression data and joining it with the matched metadata, the cleaned datasets are saved directly in the data/ folder as compressed tab-separated files. The original files in data/_raw/ are kept unchanged.

# Save the matched metadata
write_tsv(
  laml_metadata_matched,
  file = "../data/02_dat_clean_meta.tsv.gz"
)

# Save the joined gene expression data
write_tsv(
  laml_expression_joined,
  file = "../data/02_dat_clean_expr.tsv.gz"
)
